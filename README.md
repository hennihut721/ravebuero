# RaveBüro

Planung fürs Kollektiv – Termine, Kosten, Line-up, Aufgaben.

Web-Version der RaveBüro-App. Läuft auf GitHub Pages und nutzt dieselbe Firebase-Datenbank (Projekt `ravebuero-1050d`) wie die Android-App.
Zugang nur für Mitglieder, die in der App unter „Mitglieder“ freigeschaltet sind.

- `index.html` – die komplette App
- `vendor/` – Firebase JavaScript SDK 10.14.1 (compat)
